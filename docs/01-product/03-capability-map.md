# 产品能力地图

> 状态：评审中 · 版本：1.0 · 更新：2026-10-12 · 负责人：产品负责人

本文列出妙洽的全部业务能力，并说明每项能力由哪个子系统承担、通过哪些产品界面交付。它是产品规划与架构设计之间的对照表。

## 1. 一级能力

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ C1 数据供应        采集 · 证据 · 领域情报 · 实体图谱 · 检索              │
├─────────────────────────────────────────────────────────────────────────┤
│ C2 客户理解        客户上下文 · 目标配置 · 策略管理                      │
│ C3 监测发现        监测订阅 · 信号匹配 · 处置分层                        │
```

## 3. 产品界面

| 界面 | 用户 | 主要功能 | 依赖能力 |
|---|---|---|---|
| **研究工作台**（Web） | 业务开拓者、研究分析者 | 信号收件箱、发起与查看研究、证据查看、判断与反馈 | C3、C4、C5、C7 |
| **推进工作台**（Web） | 项目推进者、决策者 | 推进看板、阶段与任务、决策审批、结果复盘 | C5、C6 |
| **客户能力中心**（Web） | 管理员、业务专家 | 产品、资质、业绩、知识资产维护 | C2 |
| **策略实验室**（Web） | 管理员、业务负责人 | 自然语言调优、策略差异、历史仿真、审批、灰度、回滚 | C2、C7 |
| **市场与实体视图**（Web） | 决策者、研究分析者 | 组织画像、项目链、竞争格局、市场分布 | C1、C4 |
| **管理控制台**（Web） | 租户管理员 | 成员、角色、订阅、用量、审计、数据策略 | C9 |
| **运营控制台**（Web，内部） | 妙洽运营与分析师 | 来源健康、质量审核、人工复核队列、托管服务、客户成功 | C1、C9 |
| **企业微信 / 飞书 / 钉钉** | 全体业务用户 | 信号推送、简报、渠道内向 Agent 提问与追问、快捷反馈、分派、审批提醒 | C3、C4、C6、C8 |
| **邮件** | 管理层、外部协作者 | 定期摘要、回复式低风险反馈 | C8 |
| **API / Webhook** | 客户 IT、合作伙伴 | 领域对象、信号、研究、推进的读写与事件订阅 | C8 |
| **MCP / Skills** | 使用 AI 助手的用户 | 在 AI 助手中检索、研究、判断、反馈 | C8 |

## 4. 能力与商业目标的关系

能力是平台层的，商业目标通过**机会路径**组合这些能力。例如：

| 商业目标 | 主要使用的能力组合 |
|---|---|
| 直接投标获取 | C3 监测 → C4 资格与竞争研究 → C5 投标决策 → C6 投标推进 |
| 进入供货 | C1 中标结果与实体 → C3 中标事件监测 → C4 总包与项目研究 → C6 供货推进 |
| 规格入围 | C1 项目审批与设计信息 → C4 设计单位研究 → C6 入围推进 |
| 竞争情报 | C1 实体图谱 → C3 竞争对手监测 → C4 竞争分析 |
| 交易对手风险 | C1 司法信用与财政信息 → C4 风险研究 → C5 风险判断 |

完整目标目录见 [商业目标](../02-business/02-commercial-objectives.md)。
