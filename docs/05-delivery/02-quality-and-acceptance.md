# 质量与验收标准

> 状态：评审中 · 版本：2.1 · 更新：2026-10-16 · 负责人：产品负责人、质量负责人

平台的应用范围很广，需求本身不是瓶颈；真正决定成败的是**能否达到客户的交付预期**。本文把交付预期转化为可度量的门槛，作为应用领域发布、信息领域上线和每次重大变更的验收依据。

所有目标值为初始值，标注 **[待校准]**，按[数据、质量与组织](04-data-quality-organization.md#14-指标冻结)的阶段，以独立真实样本测量后由产品与质量负责人冻结。

## 1. 度量原则

- 每个指标都有明确的定义、样本、计算方法和负责人；
- 指标按租户、来源、信息领域、商业目标、阶段分层，不只看平均值；
- 评估集版本化，变更评估集需要评审；
- 生产指标持续计算并在运营控制台可见。

## 2. 数据层

| 指标 | 定义 | 内测门槛 | 发布门槛 |
|---|---|---|---|
| 来源覆盖率 | 参照集（官方平台抽样 + 客户实际跟进项目）中可在平台找到的比例 | ≥ 90% | ≥ 97% |
| 发现时效 | 来源发布到领域事实可用的 P95 | ≤ 2 小时 | ≤ 30 分钟（P0 来源） |
| 关键字段准确率 | 采购人、标的、预算/金额、截止时间、中标人在标注集上的准确率 | ≥ 95% | ≥ 98% |
| 字段证据覆盖率 | 关键字段带可定位证据的比例 | 100% | 100% |
| 实体自动合并精确率 | 自动合并中正确的比例 | ≥ 99% | ≥ 99.5% |
| 项目聚合精确率 | 自动归并为同一项目的正确比例 | ≥ 95% | ≥ 97% |
| 重复率 | 同一公告被识别为多个对象的比例 | ≤ 2% | ≤ 0.5% |
| 来源健康 | 关键来源连续中断后的恢复时间 | ≤ 24 小时 | ≤ 4 小时 |

## 3. 内容增强与检索层

| 指标 | 定义 | 内测门槛 | 发布门槛 |
|---|---|---|---|
| 品类分类准确率 | 增强器在标注集上的多标签分类 F1 | ≥ 0.85 | ≥ 0.92 |
| 业务标签准确率 | 关键业务标签（如“含设备供货”“允许联合体”）的精确率 / 召回率 | ≥ 0.85 / 0.80 | ≥ 0.92 / 0.90 |
| 检索相关性 | 检索评估集上的 nDCG@10 | 建立基线 | 每次索引版本切换不劣化，并持续提升 |
| 检索召回率 | 评估集中相关文档出现在前 50 条的比例 | ≥ 85% | ≥ 95% |
| 增强覆盖 | 有效期内公告完成当前生效增强器处理的比例 | ≥ 95% | ≥ 99.5% |
| 增强时效 | 快照生成到增强完成并可检索的 P95 | ≤ 30 分钟 | ≤ 10 分钟 |
| 检索延迟 | 交互式检索 P95 | ≤ 1 秒 | ≤ 500 毫秒 |

## 4. 监测与判断层

| 指标 | 定义 | 内测门槛 | 发布门槛 |
|---|---|---|---|
| 相关信号召回率 | 标注集中相关项被生成为非 `no_signal`/`excluded` 信号的比例（按目标） | ≥ 85% | ≥ 92% |
| Top-K 精确率 | 每周推送前 K 条中被用户确认相关的比例 | ≥ 60% | ≥ 75% |
| 排除正确率 | `excluded` 中确实不相关的比例 | ≥ 95% | ≥ 98% |
| 信号延迟 | 领域事件到信号生成 P95 | ≤ 10 分钟 | ≤ 1 分钟 |
| 判断否决率 | 用户否决系统判断的比例（趋势指标） | 监测 | 持续下降 |
| 可解释性 | 信号可展示命中规则与证据的比例 | 100% | 100% |

|---|---|---|---|
| 事实引用覆盖 | 报告中事实条目带有效证据的比例 | 100% | 100% |
| 事实正确率 | 黄金集上事实条目经人工核验正确的比例 | ≥ 95% | ≥ 98% |

## 6. 推进与客户价值

| 指标 | 定义 | 发布后目标 |
|---|---|---|
| 每周有效判断数 | 每活跃租户每周完成的有证据支撑的有效判断数（北极星） | 持续增长 |
| 新增有效机会 | 客户确认的、原有渠道未发现或晚发现的有效机会 | 每租户每月可量化 |
| 发现提前量 | 信号时间相对公告发布时间，或相对客户经原有渠道获知的时间（`Outcome` 的获知时间与渠道）的提前量 | 可量化 |
| 发现到决策时间 | 信号生成到决策记录的中位时间 | 持续下降 |
| 结果反馈覆盖 | 已结束推进中记录结果与原因的比例 | ≥ 70% |
| 价值记录完整 | 已结束推进的结果中带取值性质、币种与获知时间的比例；客户价值按已发生、估计、客户自报分列，不相加 | 记录（M2 起） |
| 周活跃率 | 每周至少处理一次信号的目标用户比例 | ≥ 60% |

回测与效果评估遵守时点正确规则（[learning 8.1](../03-architecture/subsystems/learning.md#81-时点正确)）：输入取当时版本，结果按获知时间计入；违反即视为评估无效。

## 8. 发布门禁

| 对象 | 门禁 |
|---|---|
| 信息领域上线 | 数据层发布门槛 + 来源权利登记完成 + 个人信息清单完成 |
| 应用领域发布 | 所依赖信息领域已上线 + 适用的数据/增强检索/监测/研究层发布门槛 + 运营与客户成功流程就绪 + 安全合规评审 + 生产迁移/恢复验收 |
| 模型、提示、模板、框架变更 | 对应能力所有者执行专业回归与发布门禁；learning 编排/汇总，不替代发布授权 |
| 策略激活（租户） | 仿真报告 + 授权审批 |
| 平台版本发布 | 全部 CI 门禁 + 契约兼容 + 预发布环境端到端测试 |

## 10. 指标执行口径

- 字段准确率按公告类型/字段分别报告。原文有值却未抽出为错误；原文未提供为“未知”，不纳入有值准确率分母但必须报告占比；原文不适用单列；模板未选项与占位“/”不能当作肯定值。冲突保留候选证据并进入复核，不取任一值冒充确定事实。
- 金额归一到币种基本单位，十进制字符串精确比较；不同标包、合同估算、预算、限价、费率不混算。时间按原始精度与时区比较，不以假造分钟提高准确率。
- 来源覆盖分母来自独立官方抽样；原型/本平台采集结果不能自证覆盖。官方抽样和客户项目分别报告，按省份、类型、采购体系分层，去重转载后统计；缺乏样本的层标为未验证。
- `INF-ORG`按企业名称/代码/登记字段验收，`INF-INVP`按审批类型/项目代码/建设单位/日期验收，`INF-CRED`按组织主体/案号/状态/日期验收。不存在的字段不机械套用采购公告标准；每领域发布前冻结适用字段表与来源清单。
- Top-K初值K=20；按活跃租户/目标的每周排序列表取至多20条，少于K记录实际数量。精确率以人工或客户确认标注为依据；未反馈不能自动视为相关，报告反馈率与未反馈数，发布评估集由独立复核补标。K及聚合方法在M2前冻结。
- 分类F1明确采用macro/micro并分别报告（发布门槛默认macro）；检索nDCG@10和Recall@50采用固定查询与分级标注。新索引与同一基线比较，首个版本需人工确认可用性，不能仅以“建立了很低的基线”通过发布。
- 时效区分来源发布→发现、发现→事实、快照→增强、事件→信号；没有可信来源时间的样本标为不可测，报告数量，不能以抓取时间替代来源发布时间。延迟按约定工作负载、窗口、成功/失败数报告。
- 每项报告评估集/规则/模型/解析器/索引版本、有效样本量、分层结果、置信区间或不确定性、负责人和复现实验方法；样本不足不得宣称已达门槛。

## 11. 阶段与运行门禁

M1真实采集/模型处理前：来源权利、个人信息清单与最小模型网关控制验收；M2真实客户内测前：权限矩阵、仿真审批、查看限额、删除更正操作、渠道安装与支持流程验收；M3真实研究前：模板/工具白名单、成本与时长限制、AI标识、引用与未知项回归。M4正式发布前：适用分层质量门槛、生产迁移、备份恢复、升级回退、值班告警与客户培训全部验收。

信息领域/应用领域内测使用对应内测值，不能声称已正式上线。费用控制以任务限额验证，研究成本评估不能因价格方案尚未形成而省略。正式收费前额外验收价格、权益、配额与账单流程。

运行验收至少包括：值班与事故责任、告警到处置演练、数据库/对象恢复和删除清单重放、事件幂等重放、主模型失败与同级备选、来源中断、迁移/升级回退。派生检索的重建可能超过一小时；全服务恢复时间含重建，应以降级窗口和实际演练解释99.9%可用性，不把权威库恢复等同于全服务恢复。
