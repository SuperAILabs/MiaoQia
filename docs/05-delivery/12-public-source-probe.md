# 首批公共来源单栏探测记录

> 日期 2026-11-19 · 范围为首批来源清单 · 本机匿名 HTTP

本文的 VPS 实测使用公共测试栈连接，已核对该连接为境外出口。各站从该出口的可达性和历史临时归档仅计入来源工程验证。境内常驻出口的覆盖单独验收。

首轮用各站自身的列表和正文处理器探测 34 个声明了公开处理器的来源。每站选一个栏目，最多观察两页和一份正文，按来源配置限频。响应字节仅在运行时内存中检查。其余 6 个首批来源中，5 个待接入处理器，1 个需要登录授权。

首轮 34 个探测中，21 个取得有限结果，13 个出现网络、列表或正文失败。17 个来源样本通过采集侧正文检查，其中 12 个在本次样本有公告键。两处安徽来源观察到翻页并取得正文。国家平台观察到翻页，抽查正文只返回概要。现行准入范围见本轮逐源复验。30 天列表范围、持续回填、附件、更正和字段解析质量分别记录。

复现单源探测时在 `data/` 使用来源声明中的栏目和限频。以下示例验证安徽工程建筑类招标栏目。

```sh
uv run --locked --all-packages mq-acquisition-fetch --validate-source anhui-ggzy-construction \
  --channel 1:1 --max-pages 2 --max-details 1 --packs ../packs
```
