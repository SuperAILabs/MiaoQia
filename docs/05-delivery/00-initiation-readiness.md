# 立项准入清单

> 状态：评审中（立项验收待项目负责人确认） · 版本：3.11 · 更新：2026-11-02 · 负责人：项目负责人

本文跟踪进入 M0 前的设计准入条件，以及后续能力首次使用前必须关闭的准备事项。人员编制、到岗与项目预算灵活处理，不作为立项准入条件；技术调用的限额、计量与审批仍按运行安全要求设计。

## 1. 等级、状态与证据

- **G0**：M0 开始前必须关闭的范围、设计与决策事项。
- **G1**：可与 M0 并行，必须在表中指定的首次使用或验收节点前关闭。
- **方案批准**：方向与规则已决定；不代表执行产出完成。
- **执行中**：正在交付具体产出。
- **产出完成**：已有可检查的文档、配置或样本，等待验收。
- **验收通过**：满足本项条件，并记录批准或验收证据。
- **待决策 / 未开始**：尚未形成有效决定或产出。

每项记录责任角色、期限、证据与关闭条件。外部维护的客户协议、法律意见、采购合同和登记无需进入代码仓库，但应在相应登记中有版本、编号、批准人和可访问位置。项目负责人确认早期客户已落实；法律授权沿用已确认结论，不用研发审查重新否定。
