# 应用领域：招投标与政企采购（APP-TENDER）

> 状态：评审中 · 版本：1.0 · 更新：2026-10-12 · 负责人：招投标领域负责人

## 1. 领域定义

招投标与政企采购应用领域服务于**参与政府、国企、事业单位等公共主体采购交易链条的各类市场参与者**，帮助他们在项目的整个生命周期中发现机会、研究取证、判断决策并推进协作。

这个领域覆盖的不只是“投标”这一个动作。一个公共项目从规划立项到履约完成，会在不同阶段为不同价值链角色产生不同的商业机会：

```text
规划立项 ──► 设计 ──► 采购 ──► 中标 ──► 合同 ──► 施工/交付 ──► 验收 ──► 运维/续约
   │          │         │        │        │          │            │         │
 规格入围   规格入围   直接投标  进入供货  金融服务   进入供货     回款跟踪   续约
 市场布局   专业服务   合作组队  分包承接  回款跟踪   分包承接     风险评估   客户经营
 客户经营             竞争情报  竞争情报                                     
```

## 4. 领域特殊约束

- **法规可变**：政府采购与招标投标的法律法规持续修订（截至本文日期，《政府采购法》修订草案已公开征求意见），采购方式、公告类型和时限等规则必须版本化配置，不得写死在代码中 **[待核验最新状态]**；
- **来源多样**：全国、省、市、县各级平台及国企自建平台格式差异大，同一项目可能在多个平台重复发布，以源平台为准；
- **项目合并困难**：多条公告属于同一项目的判断经常不确定，必须保留合并置信度与历史，宁可显示“可能相关”也不悄悄错误合并；
- **敏感对象保护**：不提供针对评标专家、监管人员的任何画像；
- **倾向性分析**：只输出客观证据对比与不确定性说明，不输出指控性结论。
