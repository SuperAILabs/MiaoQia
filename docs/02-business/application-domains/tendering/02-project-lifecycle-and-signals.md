# 项目生命周期与信号

> 状态：评审中 · 版本：1.0 · 更新：2026-10-12 · 负责人：招投标领域负责人

## 1. 项目全生命周期

一个公共项目跨越多个信息领域。招投标应用领域把它们串成一条完整的项目链：

| 阶段 | 关键事件 | 来源信息领域 | 典型时间窗口 |
|---|---|---|---|
| S1 规划与资金 | 规划发布、预算批复、专项债发行、政府投资计划 | `INF-POL`、`INF-FISC` | 采购前数月至数年 |
| S2 立项审批 | 项目备案或核准、可研批复、环评批复、用地与规划许可 | `INF-INVP` | 采购前数月 |
| S3 设计 | 设计招标与中标、初步设计批复 | `INF-PROC`、`INF-INVP` | 采购前数周至数月 |
| S4 采购准备 | 采购意向公开、招标计划、资格预审 | `INF-PROC` | 采购前数周 |
| S5 采购公告 | 招标、竞争性谈判/磋商、询价、单一来源公示、框架协议征集 | `INF-PROC` | 截止前数天至数周 |
| S6 变更澄清 | 更正、澄清、延期、终止 | `INF-PROC` | 截止前任意时点 |
| S7 开标评审 | 开标记录、候选人公示 | `INF-PROC` | 截止后数天 |
| S8 结果 | 中标/成交结果、废标/流标 | `INF-PROC` | 截止后数天至数周 |
| S9 合同 | 合同公告 | `INF-PROC` | 结果后数周 |
| S10 实施 | 施工许可、开工、进场、分包与材料采购 | `INF-INVP` | 合同后数周至数月 |
| S11 验收与付款 | 验收公告、付款信息、竣工备案 | `INF-PROC`、`INF-INVP` | 实施结束后 |
| S12 运维与续约 | 服务期满、续约、二期项目 | `INF-PROC` | 合同期满前 |

各阶段的法定时限（如采购意向公开时间、候选人公示期、合同公告时限）因交易制度而异，作为规则配置维护在领域包中 **[待核验最新法规]**。

## 2. 采购方式

采购方式影响信号类型、竞争程度和推进节奏，必须作为结构化字段识别：

| 交易制度 | 采购方式 | 对机会路径的影响 |
|---|---|---|
| 政府采购 | 公开招标、邀请招标、竞争性谈判、竞争性磋商、询价、单一来源、框架协议 | 单一来源意味着竞争空间小；框架协议意味着入围后多次成交 |
| 依法必须招标的工程建设项目 | 公开招标、邀请招标 | 候选人公示环节可提前获知中标结果 |
| 国企自主采购 | 招标、比选、询比价、竞争性谈判、直接采购、电商采购 | 规则差异大，来源分散 |

## 3. 信号分类

| 信号类型 | 代码 | 示例 | 时效价值 |
|---|---|---|---|
| 前置信号 | `SIG-EARLY` | 规划、预算、专项债、立项、可研、设计中标 | 早，允许前期介入 |
| 采购信号 | `SIG-PROC` | 采购意向、招标公告、谈判磋商公告 | 中，决定是否参与 |
| 变更信号 | `SIG-CHANGE` | 更正、澄清、延期、终止 | 紧急，影响已在推进的工作 |
| 结果信号 | `SIG-RESULT` | 候选人公示、中标结果、废标流标 | 对供货、分包、竞争情报、金融获客最关键 |
| 履约信号 | `SIG-EXEC` | 合同、施工许可、开工、验收、付款 | 对供货、回款、续约关键 |
| 主体信号 | `SIG-ENTITY` | 企业变更、资质变化、处罚、失信 | 用于风险与伙伴判断 |

## 4. 关键识别字段

为了服务所有商业目标，领域解析必须覆盖以下字段，而不仅是招标公告的基础字段：

| 字段组 | 字段 | 主要服务的目标 |
|---|---|---|
| 主体 | 采购人、代理机构、投标人、候选人、中标人、联合体成员、设计单位 | 全部 |
| 项目 | 项目名称、项目编号、审批编号、所属投资项目、标包 | 项目合并、供货、入围 |
| 标的 | 品目、规格、数量、单位、品牌与型号要求 | 投标、供货、渠道、价格 |
| 资金 | 预算、最高限价、中标金额、资金来源 | 投标、价格、风险、金融 |
| 时间 | 发布、报名截止、投标截止、开标、公示期、合同期、工期 | 全部 |
| 资格 | 资质、业绩、人员、信用、是否接受联合体、是否要求原厂授权 | 投标、组队、渠道 |
| 保证金 | 投标保证金、履约保证金、是否接受保函 | 投标、金融 |
| 方式 | 交易制度、采购方式、评标办法 | 投标、竞争 |
| 地点 | 项目地点、交付地点 | 全部 |

## 5. 跨阶段关联

项目链的价值来自跨阶段关联。关联依据（按可靠性排序）：

1. 项目编号、审批编号等明确标识；
2. 公告中显式引用的前序公告；
3. 采购人 + 项目名称 + 金额 + 时间的组合匹配；
4. 语义相似度与地点、品类一致性。

前两类可自动关联；后两类产生**候选关联**，带置信度，必要时进入人工复核。所有关联保留历史，支持撤销。
