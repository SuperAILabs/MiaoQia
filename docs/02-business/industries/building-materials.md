# 建材管材行业

> 状态：草案 · 版本：0.1 · 更新：2026-10-19 · 负责人：招投标领域团队

本文说明建材管材行业包（`IND-BUILDING-MATERIALS`）覆盖什么、服务哪些客户、在招投标应用领域中支撑哪些商业目标。品类、词表、资质与默认词表的具体内容只在 `packs/industries/building-materials/` 中定义，本文不复制；包的结构与校验见[扩展机制 2.4](../../03-architecture/04-extensibility.md#24-行业包)。

## 1. 范围

| 纳入 | 不纳入 |
|---|---|
| 塑料管材（PE、PVC、PP-R、PP 结构壁、电力与通信保护管）、金属管材（球墨铸铁、铸铁排水、钢管、钢塑复合、铜管）、玻璃钢管与混凝土管 | 阀门、水泵、计量表等设备：另建行业包，租户可以同时选择两个行业包 |
| 与管材配套采购的管件、管道附件、塑料检查井与井盖 | 管道施工、清淤、检测、修复等服务：作为默认排除词，避免误报 |
| 管材生产与安装相关的产品许可、认证与施工资质 | 医用导管、照明与电子用管等同名不同类产品 |

品类按材质再按用途细分，同时登记到国民经济行业分类（GB/T 4754-2017）的建议映射，便于企业与统计数据对齐；政府采购品目映射随 M2 交付。

## 2. 客户与目标

本行业是首发的早期使用客户所在行业（[首发范围 3.2](../application-domains/tendering/05-release-plan.md#32-首发行业包)），典型客户是区域管材厂商，同时担任厂商、投标人与渠道角色（[价值链与客户细分](../application-domains/tendering/01-value-chain-and-segments.md)）。

| 目标 | 本行业的含义 | 发布阶段 |
|---|---|---|
| A01 直接投标 | 管材集采、框架协议与小型市政项目的直接投标 | R1 / M2 |
| A02 进入供货 | 工程中标后找到总包，争取管材供货；本行业最核心的路径 | R1 / M2 |
| B03 竞争情报 | 竞争品牌在哪些项目中标、以什么价格 | R1 / M2 |
| C01 交易对手风险评估 | 总包与业主的付款风险 | R1 / M3 |
| A04 规格与品牌入围、A06 渠道与授权 | 在设计院与业主的规格中写入品牌；发展区域经销 | R2 / M4 |
| B01 重点客户经营、B02 市场研究与布局、B04 价格与报价基准 | 跟踪重点业主与区域需求、管材中标单价 | R2 / M4 |
| C02 自身资格维护、C03 履约与回款跟踪 | 资质到期、履约与回款 | R3 / M5 |

各角色的默认目标与可选目标、每条路径的发布阶段以 `APP-TENDER` 的角色模板与覆盖矩阵为准（`packs/application_domains/tendering/roles/`、`coverage.yaml`）。

## 3. 行业包提供什么

- **品类分类**：管材与管件两棵品类树，供信号匹配、画像与统计使用；
- **词表**：产品词与同义词（含俗称与型号写法）、规格词（材质等级、压力等级、口径）、用途标签；
- **资质模板**：涉水卫生许可、特种设备（压力管道元件）制造许可、产品认证与体系认证、市政与机电施工资质等，用于 A01 的资格判断与画像填写；
- **默认排除词**：A01 的策略模板以 `vocab.exclude_terms` 引用，默认排除管道服务类、医用与电子类“管”；关注词表 `vocab.focus_terms` 随 M4 启用。
