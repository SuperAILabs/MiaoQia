# AI 平台子系统（ai-platform）

> 状态：评审中 · 版本：1.0 · 更新：2026-10-12 · 平面：平台 · 首期部署单元：`platform`（模型推理服务为独立基础组件）

## 1. 使命

为平台中所有 AI 使用场景提供统一、受治理、可计量、可评估的模型能力，使业务子系统无需关心具体模型供应商。

## 2. 职责

- **模型网关**：统一的生成、结构化输出、嵌入、重排、OCR/版面等模型调用接口；
- **路由**：按任务类型、数据分级、租户策略、模型备案状态、地域、成本、质量和可用性选择模型；
- **模型目录**：模型供应商、模型版本、能力、价格、备案信息、可用区域、上下文长度；
- **提示注册**：提示模板、版本、输出 Schema、适用模型、评估结果；
- **护栏**：输入净化与不可信内容隔离、输出 Schema 校验、敏感信息检测与脱敏、内容安全检查；
- **计量与记录**：每次调用的模型、提示版本、令牌、延迟、成本、调用方、租户、结果状态；
- **缓存**：对确定性任务（如公共文档解析）的结果缓存，仅限公共域；
- **私有模型**：自部署开源模型推理服务的接入与容量管理。

## 3. 内部组件

`gateway`、`router`、`model_catalog`、`prompt_registry`、`guardrails`、`embedding_service`、`metering`、`inference_pool`（自部署模型的推理服务，独立基础组件）。

## 4. 拥有的数据

`ModelProvider`、`ModelVersion`、`RoutingPolicy`、`PromptTemplate` / `PromptVersion`、`Invocation`（调用记录，敏感内容不落日志，只存哈希与引用）。

## 5. 接口

| 接口 | 说明 |
|---|---|
| `Generate(task, prompt_ref, inputs, schema, context)` | 结构化生成；`context` 包含租户、数据分级、调用方、预算 |
| `Embed(texts, purpose)` | 向量化 |
| `Rerank(query, candidates)` | 重排 |
| `GetPrompt` / `RegisterPromptVersion` | 提示管理 |
| `GetModelCatalog` / `UpdateRoutingPolicy` | 目录与路由策略管理 |

## 6. 事件

**发布**：`ai_platform.invocation.recorded.v1`（计量）、`ai_platform.model.degraded.v1`。

## 7. 路由规则示例

| 条件 | 路由 |
|---|---|
| 数据分级为“敏感”或租户要求不出域 | 仅私有部署模型 |
| 公共域文档解析 | 成本优先的已备案模型，结果可缓存 |
| 研究规划与归纳 | 质量优先的已备案模型 |
| 主模型不可用 | 同等级备用模型；无备用时返回明确错误，不降级到不合规模型 |

默认只使用境内处理的模型。任何境外模型调用需经数据分级、合同与跨境合规评估并在路由策略中显式启用。

## 8. 安全要点

- 模型供应商合同与配置均需禁止使用客户数据训练；
- 提示中的外部内容与客户文档以结构化方式隔离，并标注为不可信数据；
- 调用记录不保存敏感原文；需要调试时通过受控的短期采样并审计。
