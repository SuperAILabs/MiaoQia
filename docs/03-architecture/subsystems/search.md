# 检索与索引子系统（search）

> 状态：评审中 · 版本：1.1 · 更新：2026-10-17 · 平面：数据供应

## 1. 使命

为用户、Agent 和监测匹配提供统一、快速、权限正确的检索能力，包括全文、结构化过滤、语义与混合检索，以及“一条新事实命中了哪些订阅”的反向匹配。

## 2. 职责与非职责

**职责**

- 索引投影：组合规范化文档（L1）、领域事实结构化字段（L2）与增强结果（L3），构建检索索引（L4，派生数据，可完全重建）；
- 索引族：文档索引（公告级）、分块索引（段落级，供语义检索与 Agent 研究）、领域事实索引、实体索引、订阅反查索引；
- 索引版本化：映射、分析器、词表或生效增强器变化时构建新版本索引，评估后别名切换；
- 中文全文检索：分词、同义词、行业词表；
- 语义检索：文本向量化（经 `ai-platform` 的嵌入服务）与向量检索；
- 混合检索与重排；
- 订阅反查（percolation）：注册租户的监测条件为查询，新事实到来时反查命中的订阅；
- 租户私有知识检索：租户知识资产在隔离索引中的检索；
- 检索权限过滤：按来源权利（展示级别与允许用途，[数据架构第 12 节](../02-data-architecture.md#12-来源权利与数据权益)）与租户可见性过滤结果。

**非职责**

- 不是任何数据的权威来源；
- 不做业务判断与排序策略（业务排序属于 `detection` 与 `assessment`）。

## 3. 内部组件

| 组件 | 说明 |
|---|---|
| `indexer` | 事件消费、文档组装（从对象存储读取 L1/L3，从接口获取 L2）、增量写入 |
| `index_builder` | 新版本索引的批量构建（Temporal 工作流，读语料快照与增强结果） |
| `relevance` | 检索相关性评估：评估集回放、nDCG/召回率计算、影子查询比对 |
| `mappings` | 索引映射，由信息领域包注册 |
| `query_service` | 查询解析、权限过滤、混合检索、高亮 |
| `percolator` | 订阅查询注册与反查；查询由策略编译下推而来，规则见 [策略 DSL](../11-policy-dsl.md#6-编译与下推) |
| `tenant_index_manager` | 租户私有索引的创建、删除与隔离 |

## 4. 拥有的数据

- 公共域索引：按索引族、信息领域与时间分区；每个索引带映射版本与构建标识，通过别名访问；
- 索引版本登记：索引版本、来源数据范围、所用增强器版本、评估结果、别名状态；
- 订阅查询索引：租户的监测条件（带租户标识，仅 `detection` 可注册和反查）；
- 租户私有索引：每租户独立索引（或独立命名空间），存放其知识资产的检索投影。

## 5. 接口

| 接口 | 类型 | 说明 |
|---|---|---|
| `Search` | 查询 | 统一检索：查询、过滤、排序、分页、高亮；调用方租户与用途决定可见范围 |
| `SemanticSearch` / `HybridSearch` | 查询 | 语义与混合检索 |
| `RegisterWatchQuery` / `RemoveWatchQuery` | 命令 | `detection` 专用 |
| `Percolate` | 查询 | `detection` 专用：给定事实返回命中的订阅 |
| `SearchTenantKnowledge` | 查询 | 租户知识检索 |
| `SearchChunks` | 查询 | 分块级检索，返回分块文本、证据定位与所属快照（供 Agent 研究工具） |
| `BuildIndexVersion` | 命令 | 构建新版本索引（异步） |
| `EvaluateIndexVersion` | 命令 | 对新版本执行相关性评估与影子比对 |
| `SwitchAlias` / `RollbackAlias` | 命令 | 切换或回退别名 |

## 6. 事件

**公共实例消费**：公共域的 `evidence.enrichment.completed.v1`、`evidence.enricher.promoted.v1`、`domain.fact.upserted.v1`、`entity.*`、来源权利变更及公共删除控制事件，不消费租户知识或订阅事件。

**租户实例消费**：所属 Cell 的知识变更与删除控制事件；订阅由 detection 的命令接口注册，反查事实由 detection 提交。公共来源撤权通过公共引用失效控制通知同步到各 Cell。租户知识的解析/增强事件随租户文档管线实现时单独定义，不能复用公共 evidence 主题来携带租户内容。

**发布**：`search.index.version_built.v1`、`search.alias.switched.v1`。

## 7. 扩展点

- 信息领域包注册索引映射、分析器与字段权重；
- 行业包注册同义词与词表；
- 重排模型可插拔；
- 排序配置（字段权重、标签加权、混合检索融合参数）版本化，随索引版本评估与发布。

## 8. 伸缩与可靠性

- 读写分离：索引写入异步，查询节点水平伸缩；
- 索引落后于权威数据时，接口返回索引时间点；关键流程（如判断）始终回到权威数据核实；
- 索引可从本数据域的版本化制品（L1、L3）与数据所有者公开接口/导出的事实快照（L2）完全重建，不直接查询其他子系统数据库，重建期间使用别名切换实现零停机；旧版本保留一个周期以便回退；
- 检索质量通过相关性评估集持续度量，任何索引版本切换前必须评估不劣化。

## 9. 安全要点

- 每个查询必须携带由认证上下文派生的租户与用途，服务端强制注入过滤条件，调用方不能绕过；
- 租户私有索引与公共索引物理分开；租户删除时同步删除其索引；
- 面向用户与外部接口的公共数据检索受暴露策略约束（结果上限、翻页深度、配额），Agent 研究工具的检索不受用户侧上限约束但全程审计，见 [安全与租户](../06-security-and-tenancy.md#7-公共数据暴露控制)。

## 10. 开放问题

1. 中文分词与行业词表的维护流程；
2. 向量模型选型与向量维度。

## 11. 数据域实例与评估所有权

本子系统复用实现但分别运行公共与单元级租户实例。公共实例只持有公共投影；租户实例持有所属 Cell 的知识与订阅投影，收到公共事实后反查本单元订阅。两种实例分别管理索引、凭证、缓存、别名、队列、重建和删除范围；公共重建不能读取租户订阅或知识。查询按范围路由，不能以公共实例提供统一入口而跨域读取租户索引。

公共相关性基线与公共评估快照由 search 维护，租户反馈集由 learning 管理。search 拥有检索指标、索引评估执行、门禁与别名发布决定；租户评估在租户实例执行。公共实例只能接收经 governance 审批、明确授权并去标识化的不可变评估快照，不能同步查询 learning。
