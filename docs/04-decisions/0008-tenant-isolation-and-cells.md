# ADR-0008：多租户隔离与租户单元

> 状态：已批准 · 日期：2026-10-12（2026-10-13 按 ADR-0014～0017 审查修正） · 决策者：首席架构师、产品负责人 · 批准：项目负责人

## 背景

跨租户数据暴露必须为零；平台需支撑大量租户、专属部署与私有部署。

## 决策

- 租户身份只来自已验证令牌；
- 隔离在身份、应用、数据库（RLS）、对象存储（前缀 + 租户密钥，经 OpenBao 信封加密，ADR-0015）、检索（私有索引物理分离）、事件（单元主题）、缓存、模型、日志各层同时实施；客户授权文档的解析以租户单元为范围部署（ADR-0014）；
- 客户智能平面按**租户单元（Cell）**部署；数据供应平面与平台平面共享；首期一个共享单元，单元标识与路由从第一天存在；
- 专属单元与私有部署使用同一套代码与部署清单。

## 后果

- 正面：水平扩展与专属部署无需改造；
- 代价：跨单元的平台级统计需经治理审批与去标识化。
