# ADR-0010：受治理的 Agent 运行时

> 状态：已批准 · 日期：2026-10-12 · 决策者：首席架构师、产品负责人 · 批准：项目负责人

## 背景

Agent 研究是核心差异化能力，但必须可追溯、可控成本、防注入、不越权。

## 决策

- 自研 Agent 运行时，构建在 Temporal 工作流之上，不依赖第三方 Agent 框架；
- Agent 只能在**研究模板**声明的工具白名单、步骤与预算内运行；
- 研究工具全部只读，由子系统公开查询接口组合而成，以研究发起者身份执行授权；
- 所有模型调用经模型网关（前期只接境内已备案供应商 API，ADR-0015）；外部内容作为不可信数据隔离；
- 报告强制区分事实、推断、未知项、建议，事实必须通过引用校验；
- 模板、提示与模型变更须先通过回归评估。

## 后果

- 正面：研究质量与成本可控、全程可审计；
- 代价：开放式探索能力受限；模板需要领域团队持续维护。
