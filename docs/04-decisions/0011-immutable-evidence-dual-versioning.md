# ADR-0011：证据不可变与双版本

> 状态：提议 · 日期：2026-10-12 · 决策者：首席架构师、产品负责人

## 背景

Tender Intel 已验证：原始证据不可变、来源版本与解析版本分离、判断固定引用版本，是可信与可重放的基础。

## 决策

作为平台不变量：

- 原始制品按内容哈希不可变存储；
- 来源内容变化产生新快照；解析器升级或人工修正产生新解析修订；两者分别记录；
- 领域事实版本引用解析修订；“当前版本”是指针；
- 研究报告、判断与决策固定引用其依据的全部版本，可按版本重放；
- 客户反馈不得改写公共事实。

## 后果

- 正面：任何结论都能回到原文并解释“当时为什么这样判断”；
- 代价：存储增长；需要版本感知的查询与清理策略。
