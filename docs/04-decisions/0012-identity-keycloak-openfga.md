# ADR-0012：身份与授权：Keycloak + 关系型授权

> 状态：已批准 · 日期：2026-10-12 · 决策者：首席架构师、产品负责人 · 批准：项目负责人

## 背景

需要支持企业 SSO（企业微信、钉钉、飞书、SAML/OIDC）、OAuth 2.1（含 MCP 客户端）、细粒度资源授权与审批。

## 决策

- 身份提供者使用 Keycloak（自建高可用），负责登录、联合身份与令牌签发；
- 授权使用关系型授权服务（OpenFGA）表达租户、组织、角色、资源归属与协作关系，结合属性条件；
- 租户目录、审批与支持访问由 `identity` 子系统管理；
- 所有子系统通过统一授权 SDK 调用授权决策点。

## 后果

- 正面：标准协议、可私有部署、授权模型可表达复杂协作；
- 代价：授权关系需与业务数据保持同步（通过事件维护）；需要授权决策的缓存与性能测试。
