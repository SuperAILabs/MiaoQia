# ADR-0014：基础设施开源自建优先

> 状态：已批准 · 日期：2026-10-13 · 决策者：项目负责人、首席架构师

## 背景

项目负责人确定方向：不依赖任何云厂商的专有服务，能自建的开源方案全部自建，除非托管价格优势明显。专属单元与私有部署本就要求同一套清单可离线运行；搭建工作主要由编码 Agent 承担，但升级、备份恢复、扩容与故障处理仍是持续成本。

## 决策

1. 云厂商只作为 **IaaS 供应商**（虚拟机、云盘、VPC、四层负载均衡、带宽），不使用其 PaaS 专有能力。具体组件见 [技术选型](../03-architecture/08-technology-stack.md)。
2. 组件必须开源、可离线安装，许可证允许向私有部署客户分发；AGPL 组件随私有部署分发前经法务确认；已改为非开源许可的组件选用其开源分支（Valkey、OpenTofu、OpenBao）。
3. **价格例外**：托管服务在同等可靠性下总成本低 30% 以上（含人力与冗余），且只经标准协议使用时允许托管；被托管组件必须在 `staging` 或私有部署包中以自建方式持续运行，保证切换路径可用。
4. 当前唯一的价格例外是**生产环境对象存储**：使用 IaaS 供应商对象存储，只用 S3 标准协议；私有部署与 `staging` 使用 Ceph RGW。
5. IaaS 供应商按报价、区域与可用区、等保配套、对象存储价格、出口地址资源选择（立项清单 C1），可在不同云与自有机房之间迁移。

对象存储例外的依据（每 100 TB 有效容量，单价为公开报价量级 **[待核验]**）：

| 方案 | 估算月成本 |
|---|---|
| 公有云对象存储（标准型，约 0.12 元/GB/月） | 约 1.2 万元 |
| 公有云虚拟机 + 云盘自建 Ceph（纠删码 4+2，云盘约 0.35 元/GB/月） | 约 5 万元以上 |
| 自有机房大容量服务器 | 低于公有云对象存储，需硬件与机房 |

其他组件（PostgreSQL、Kafka、OpenSearch、Valkey）在虚拟机上自建的成本通常不高于托管溢价，不触发例外；C1 报价完成后按本规则复核一次。

## 备选

- **托管优先**：初期运维少，但形成厂商锁定，私有部署无法复用清单，扩展与版本受托管白名单限制；
- **对象存储也自建**：在公有云上成本约为托管的数倍。

## 后果

- 正面：SaaS、专属单元与私有部署使用同一套清单；可在不同云与自有机房之间迁移；组件版本与扩展自主（例如 PostgreSQL 扩展不受白名单限制）；
- 代价：平台工程团队承担升级、备份恢复演练、扩容与故障处理，需要值班与演练制度。
